# 네온 잭팟

심볼을 모아 나만의 슬롯을 만드는 슬롯 덱빌딩 게임입니다. 심볼끼리 엮일수록 점수가 불어나고, 스테이지마다 목표 점수를 넘겨야 살아남습니다.

## 실행

`index.html` 파일 하나로 동작합니다. 브라우저에서 열면 바로 플레이할 수 있고, 폰과 PC 모두 지원합니다.

## 규칙

| 항목 | 내용 |
|---|---|
| 스핀 | 내 심볼 중 최대 15개가 가로 5칸, 세로 3칸 슬롯판에 무작위로 깔림 |
| 점수 | 칩 × 배수. 칩은 심볼 값의 합 |
| 심볼 효과 | 붙어 있거나 같은 줄에 있는 심볼끼리 값을 올려 줌 |
| 줄 맞추기 | 가로로 같은 심볼 3개면 배수 2배, 4개면 3배, 5개면 5배. 여러 줄이면 계속 곱해짐 |
| 재스핀 | 정산 전에 세로줄 하나를 다시 돌림. 스테이지마다 2회 |
| 심볼 추가 | 스핀이 끝날 때마다 3개 중 하나를 추가하거나 건너뜀 |
| 스테이지 | 스핀 5번 안에 목표 점수를 넘기면 클리어. 남은 스핀 하나당 제거권 1개 |
| 모듈 | 스테이지를 넘길 때마다 3개 중 하나 선택. 게임 끝까지 적용 |
| 승리 | 10스테이지 돌파. 이후 계속 도전 가능 |

## 구성

규칙 계산과 화면 연출이 모두 `index.html` 안에 들어 있습니다. 심볼은 `SYM`, 모듈은 `MOD`, 스테이지별 목표 점수는 `QUOTA` 값을 고치면 바뀝니다. 점수 계산은 `calc` 함수 하나에 모여 있습니다.
