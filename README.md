# 네온 스핀 디펜스

2099년 네온 시티를 배경으로 한 슬롯 디펜스 게임입니다. 슬롯을 돌려 유닛을 뽑고, 몰려오는 기계들로부터 코어를 지킵니다.

## 실행

`index.html` 파일 하나로 동작합니다. 브라우저에서 열면 바로 플레이할 수 있고, 폰과 PC 모두 지원합니다.

## 규칙

| 항목 | 내용 |
|---|---|
| 스핀 | 칩을 쓰고 릴 3개를 돌립니다. 나온 심볼의 유닛이 소환됩니다 |
| 같은 심볼 2개 | 2레벨 유닛 하나로 소환 |
| 같은 심볼 3개 | 잭팟. 3레벨 유닛 소환, 모든 유닛 6초 오버클럭 |
| 칩 심볼 | 유닛 대신 칩 획득 |
| 홀드 | 릴을 눌러 다음 스핀에 고정. 홀드 하나당 칩 추가, 최대 2개 |
| 정원 초과 | 새 유닛이 같은 종류 유닛을 강화. 같은 종류가 없으면 가장 약한 유닛을 강화 |
| 임플란트 | 웨이브를 막을 때마다 3개 중 하나 선택 |
| 승리 | 20웨이브 방어 |

## 유닛

| 유닛 | 역할 |
|---|---|
| 블레이드 | 근접 공격수 |
| 거너 | 원거리 사격. 드론 공격 가능 |
| 해커 | 적 3기를 동시에 공격하고 느리게 만듦 |
| 실드봇 | 체력이 높은 방패 역할. 드론 공격 불가 |

## 구성

코드, 그림, 효과음이 모두 `index.html` 안에 들어 있습니다. 그림은 코드로 그린 도트이고, 외부 이미지 파일은 없습니다. 난이도 수치는 파일 안의 `CFG`, `UT`, `ET` 값을 고치면 바뀝니다.
